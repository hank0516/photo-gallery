# Implementation Plan: Private Photo Gallery

**Branch**: `001-photo-gallery` | **Date**: 2026-08-02 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-photo-gallery/spec.md`

---

## Summary

Build a private photo gallery web application where users authenticate via Google OAuth 2.0 and
access only the albums they have been explicitly granted permission to view. Photos are stored on
Linode Object Storage; the server stores only metadata. The system consists of a FastAPI REST
backend (integrated into the existing server infrastructure) and a Vue 3 SPA frontend.

---

## Technical Context

**Language/Version**: Python 3.12 (backend), Node 20 + Vue 3 (frontend)

**Primary Dependencies**:
- Backend: FastAPI, uvicorn, SQLAlchemy 2, PyMySQL, authlib, boto3, Pillow, python-jose, python-multipart
- Frontend: Vue 3, Vite, Vue Router 4, Pinia, Axios

**Storage**: MariaDB (user/album/photo metadata + permissions), Linode Object Storage (all media files)

**Testing**: pytest + httpx (backend), Vitest + Vue Test Utils (frontend)

**Target Platform**: Linux server (Debian), modern browsers (Chrome, Safari, Firefox) + mobile responsive

**Project Type**: Web application — decoupled SPA frontend + REST API backend

**Performance Goals**:
- Album grid (200 photos) loads in < 3 seconds
- 10 MB photo upload completes in < 30 seconds
- View mode switch: < 0.5 seconds (no network request)
- Search across 1,000 photos: < 2 seconds

**Constraints**:
- No media files stored on application server
- All authentication via Google OAuth 2.0 only
- HTTPS only; served behind existing Apache reverse proxy
- < 50 concurrent users

**Scale/Scope**: Small private system; < 50 users, expected tens of thousands of photos long-term

## Constitution Check

| Principle | Requirement | Design Decision | Status |
|---|---|---|---|
| I. Security | Google OAuth only; all routes authenticated | JWT session token issued post-OAuth; every API endpoint validates token | ✓ Pass |
| II. Cloud Storage | No media on server | boto3 uploads directly to Linode Object Storage; only metadata in DB | ✓ Pass |
| III. API-Driven | FastAPI backend + Vue 3 SPA | Fully decoupled; SPA consumes REST API only | ✓ Pass |
| IV. Permission Model | Per-user per-album roles | `permissions` table; every album query filtered by caller's roles | ✓ Pass |
| V. Performance | Auto-thumbnails; lazy loading | Pillow generates 300px + 800px on upload; frontend uses IntersectionObserver | ✓ Pass |

No violations. No complexity justification needed.
